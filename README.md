# AI-Python-Learning 🚀

A comprehensive repository showcasing AI, Machine Learning, Natural Language Processing (NLP), Speech Processing, and Python development projects.

## 📌 Short Description
**AI-Python-Learning** contains machine learning pipelines, NLP experiments (Named Entity Recognition, Intent Prediction), speech-to-text processing using Whisper, parallel computing implementations, and assistive technology solutions such as a voice-driven Personal Diary for the Visually Impaired.

---

## 📂 Key Projects & Modules

| Module / Directory | Description | Key Technologies |
| :--- | :--- | :--- |
| **NER-System-main** | End-to-end Named Entity Recognition (NER) training, EDA, and inference pipeline. | PyTorch / Transformers / Jupyter |
| **Personal Diary (PVI)** | Voice-assisted personal diary application designed for visually impaired individuals (`PersonalDiaryforVisualImpared`, `Visual_Impired_Diary`, `Moiz_pvi.py`). | Python, Speech Recognition, NLP, Web APIs |
| **Speech & Audio Processing** | Speech-to-text conversion and audio transcription tests (`whisperchk.py`). | OpenAI Whisper, PyAudio |
| **Intent Prediction** | Natural language intent classification and query processing (`intent_predict.py`, `nerchk.py`). | Machine Learning / Scikit-learn / NLP |
| **FYP Training** | Machine Learning model training pipelines, datasets, and backend controller architectures (`FYP_Training`, `Fyp_train`, `Fyp_training_ml`). | Python, Data Analytics, Pandas |
| **Parallel & Distributed Computing** | Multi-threaded / distributed parallel processing tasks (`Pdc_Project.py`, `pdc_2.py`). | Python Multiprocessing & Concurrency |
| **Classic Python Projects** | Core programming and logic games like Hangman (`HangmanGame.py`). | Pure Python |

## 🛠️ Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/AI-Python-Learning.git
   cd AI-Python-Learning
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Linux/macOS:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r NER-System-main/requirements.txt
   ```
